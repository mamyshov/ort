# ORT Prep — подготовка к ОРТ

Сайт для подготовки к ОРТ (общереспубликанское тестирование, Кыргызстан): банк вопросов, тренировка по темам, пробные тесты с таймером, статистика, ИИ-разбор ошибок. Часть вопросов бесплатна, остальное за платный доступ. Основа взята из проекта `course-platform` (вход, роли, платежи, ИИ).

## Структура ОРТ в проекте

- **Основной тест** (`section_kind = main`, код `main`): темы математика, аналогии, чтение и понимание текста, грамматика. Для всех.
- **Тест по языку**, 50 вопросов: `kyrgyz` для кыргызоязычных школ, `russian` для русскоязычных. Какой показывать первым, определяет `profiles.school_language`.
- **Предметные** (`subject`): химия, биология, физика, математика, история, английский, немецкий, кыргызская и русская литература. Создаются неопубликованными, владелец включает по мере загрузки вопросов.
- Начальные разделы и темы создаёт миграция `0002_sections.sql`.

## Стек

- Next.js (App Router) + TypeScript + Tailwind. Один проект: публичные страницы, кабинет ученика (`/app`), админка (`/admin`).
- PostgreSQL 14+, миграции в `db/migrations/`. Вход свой: пароли scrypt, сессии в таблице `sessions` (хранится sha256 токена), cookie httpOnly. Запросы пользователя идут в транзакции с `app.user_id` и ролью `authenticated`, поэтому RLS действует и при ошибке в коде.
- Два языка интерфейса и вопросов: русский (по умолчанию) и кыргызский. next-intl, тексты в `messages/{ru,ky}.json`. Тексты вопросов хранятся как `{"ru": "...", "ky": "..."}`.
- ИИ: ключ только на сервере, суточные лимиты (`ai_usage`), общий кэш ответов (`ai_cache`). Одна функция: разбор ошибки (`src/lib/ai/features.ts`).

## Роли

`student`, `manager`, `owner`. Права записаны в RLS и проверяются `npm run test:db`.

- Владелец: всё (банк вопросов, разделы, пробные тесты, пакеты, ученики, платежи, журнал).
- Менеджер: ученики и доступ, платежи и возвраты. Вопросы и ключи не видит и не правит.
- Любое действие сотрудника пишется в `audit_log`.

## Правила работы

- Правильные ответы и разборы лежат в `question_keys`, ученик читать их не может. Ответы проверяет и баллы считает сервер (`src/lib/ort.ts`); таблица `attempts` ученику только на чтение.
- Вопрос нельзя опубликовать без правильного ответа (триггер `questions_require_key`). Без ответа он остаётся черновиком.
- Платные вопросы защищены RLS (`has_premium()`), а не только скрыты в интерфейсе. Бесплатные помечены `is_free`.
- Повторы вопросов: уникальный `fingerprint` (строгий: регистр, пробелы, кавычки и тип тире не важны; **знаки препинания и дефисы важны**, потому что в вопросах по орфографии и пунктуации варианты различаются именно ими). `loose_fp` без знаков нужен только для списка «похожих» при загрузке. Не ослаблять строгий отпечаток.
- Не выдумывать содержимое вопросов и правильные ответы. Если ключа нет, вопрос остаётся черновиком. Если при копировании из документа пострадал текст (пропали знаки или варианты), вопрос не загружается и показывается владельцу.
- Платёж провайдера записывается один раз (`method + provider_ref`), доступ открывается только после `paid` (`settlePayment` в `src/lib/payments`). Возврат закрывает подписки этого платежа.
- Платежи, попытки и учёт ИИ пишутся только серверным подключением (`service()` в `src/lib/db.ts`), оно не попадает в браузерный код.
- Любая новая таблица сразу получает `enable row level security`, политики и проверку в `db/tests/rls.test.mjs`.
- Тексты на кыргызском от ИИ или машинного перевода проверяет живой человек до публикации. Тексты интерфейса на кыргызском в `messages/ky.json` написаны ИИ и ждут проверки носителем.
- Мобильный вид основной. Строки интерфейса только через `messages/*.json`.
- Секреты не коммитить. Шаблон переменных: `.env.example`.

## Загрузка вопросов

Админка → «Загрузка»: JSON или CSV, сначала «только проверить» (ничего не сохраняет, показывает повторы, похожие и ошибки). Формат описан на странице и в `src/lib/questions.ts` (`ImportItem`). Поле `correct` не обязательно. Вопросы по фото или документам готовит Claude в этот JSON.

## Команды

- `npm run dev` — запуск для разработки.
- `npm run db:start|stop|reset|migrate|seed` — локальная база (порт 54329) и демо-данные (owner/manager/student@demo.local, пароль demo12345; несколько ЯВНО демонстрационных вопросов `[Демо]`). Демо не запускать на рабочей базе.
- `npm run owner -- почта "Имя"` — создать владельца на рабочей базе.
- `npm run build`, `npm run lint`, `npm run test:db`.
