# ORT Prep

Подготовка к ОРТ: банк вопросов, тренировка по темам, пробные тесты с таймером, статистика по темам и ИИ-разбор ошибок. Русский и кыргызский языки. Подробные правила для разработки: `CLAUDE.md`.

## Запуск для разработки

Нужны Node 22 и PostgreSQL 16 (серверные программы).

```bash
npm install
cp .env.example .env.local     # добавьте PAYMENTS_MOCK=1 и SITE_URL=http://localhost:3000
npm run db:start               # локальная база на порту 54329 (выведет DATABASE_URL)
npm run db:migrate
npm run db:seed                # демо-пользователи и несколько демо-вопросов
npm run dev
```

Демо-вход (пароль `demo12345`): `owner@demo.local`, `manager@demo.local`, `student@demo.local`.

## Рабочая база

```bash
npm run db:migrate
npm run owner -- owner@example.com "Имя Фамилия"   # создать владельца
```

Дальше в админке: «Пакеты» (цены), «Разделы» (проверить темы), «Загрузка» (вопросы), «Пробные тесты».

## Что нужно получить

| Что | Зачем |
|---|---|
| Вопросы и правильные ответы | Наполнение банка (загрузка через админку) |
| Цены и сроки пакетов | Платный доступ |
| Юридический текст оферты | Приём платежей |
| Ключ ИИ (`ANTHROPIC_API_KEY`) | Разбор ошибок |
| Resend (`RESEND_API_KEY`, `MAIL_FROM`) | Сброс пароля и письма после оплаты |
| ЭЛСОМ/Kaspi номера или Finik | Приём оплаты |
| Проверка кыргызских текстов | Тексты интерфейса написаны ИИ |
