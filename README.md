# Платформа онлайн-курсов

Своя замена связке ClickFunnels и отдельного кабинета: страница вебинара, продающая страница с таймером, оплата, кабинет ученика, админка с ролями, экзамены, сертификаты, сообщения в мессенджеры и функции ИИ. Интерфейс на русском, кыргызском и английском.

Подробные правила для разработки: `CLAUDE.md`. Полное ТЗ: https://claude.ai/code/artifact/96b4070c-608b-4231-b975-664e1911901f

## Запуск для разработки

Нужны Node 22 и PostgreSQL 16 (серверные программы).

```bash
npm install
cp .env.example .env.local     # для разработки добавьте PAYMENTS_MOCK=1 и SITE_URL=http://localhost:3000
npm run db:start               # локальная база на порту 54329 (выведет строку подключения для DATABASE_URL)
npm run db:migrate
npm run db:seed                # демо-данные
npm run dev
```

Демо-вход (пароль у всех `demo12345`): `owner@demo.local`, `manager@demo.local`, `teacher1@demo.local`, `student@demo.local`.

Проверки: `npm run lint`, `npm run build`, `npm run test:db` (правила доступа в базе).

## Выход в продакшен

1. **База.** Любой PostgreSQL 14+ (свой сервер или управляемый). Приложение подключается как владелец таблиц. Применить `npm run db:migrate`. Затем создать владельца: `npm run owner -- почта "Имя"` (пароль спросит скрыто).
2. **Сайт.** Любой хостинг для Node (Vercel, Railway, свой сервер). Заполнить переменные из `.env.example`. `SITE_URL` — настоящий адрес сайта с `https://`. Тестовая оплата и пробная отправка сообщений на настоящем адресе не работают.
3. **Расписание.** Раз в минуту вызывать `GET /api/cron/messages` с заголовком `Authorization: Bearer <CRON_SECRET>`: так уходят напоминания о вебинаре и письма об оплате.
4. **Домен и почта.** Подключить домен, для почты — отправителя в Resend (`RESEND_API_KEY`, `MAIL_FROM`).

## Что нужно получить от заказчика и провайдеров

| Что | Где используется | Статус |
|---|---|---|
| Финик: договор и документация API | оплата для Кыргызстана (`src/lib/payments/finik.ts`, `/api/webhooks/finik`) | в коде только заготовка, API не реализован |
| Номера ЭЛСОМ и Kaspi, источник уведомлений о переводах | `ELSOM_PHONE`, `KASPI_PHONE`, `POST /api/webhooks/transfer` | приём и автоподтверждение готовы, нужен источник уведомлений |
| Bunny Stream: библиотека и ключи | видео (`BUNNY_STREAM_*`) | подпись ссылок написана, с настоящим аккаунтом не проверялась |
| WhatsApp: Cloud API или посредник, одобренные шаблоны | `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_ID` | отправка написана, с настоящим аккаунтом не проверялась |
| Telegram-бот | `TELEGRAM_*`, вебхук `/api/telegram/webhook` | готово, нужен токен бота |
| Ключ Anthropic | `ANTHROPIC_API_KEY` | без ключа ИИ на настоящем сайте отключён |
| Пиксель Facebook | `NEXT_PUBLIC_FB_PIXEL_ID` | события PageView, Lead, InitiateCheckout, Purchase в браузере |
| Текст оферты, цены | `/terms` (сейчас временный текст), пакеты в базе | заполнить |

## Известные ограничения

- Тексты на кыргызском (интерфейс, шаблоны сообщений, переводы ИИ) нужно показать носителю до запуска.
- Пиксель Facebook работает только в браузере, серверная отправка событий (Conversions API) не сделана.
- Ограничение частоты форм хранится в памяти сервера: подходит для одного экземпляра.
- Сертификат выдаёт преподаватель или владелец вручную, оформление PDF-версии не делалось (есть страница для печати).
